# Dependency update policy

Dependency updates are reviewed as isolated maintenance changes. Dependabot provides visibility and pull requests; it is not an automatic merge mechanism.

## Monitored ecosystems

Dependabot checks these ecosystems weekly:

- Go modules at the repository root;
- frontend packages and the pnpm lockfile under `frontend/` through the npm ecosystem integration;
- GitHub Actions workflows;
- the Dockerfile under `deploy/build/`.

## Pull request grouping

Routine minor and patch version updates are grouped per ecosystem to reduce review noise. Major version updates do not match those groups and therefore remain separate pull requests for explicit compatibility review.

Security updates are surfaced in dedicated security groups so they can be prioritized independently of routine maintenance.

## Merge rules

Dependency pull requests are never assumed safe solely because Dependabot opened them. Before merge they must:

1. stay scoped to the dependency batch under review;
2. document material behavior or compatibility changes;
3. pass the repository's full CI matrix;
4. preserve architecture and credential-handling guardrails;
5. avoid bundling ChatGPT provider protocol changes with dependency maintenance.

No automatic merge policy is enabled by this configuration.

## Ecosystem-specific rules

### Go

Security and foundational modules are prioritized. Large module-graph changes should be split into attributable batches. Avoid broad `go mod tidy` cleanup in a security-only PR when it would remove or reclassify unrelated historical dependencies.

### Frontend

Major runtime or build-tool upgrades are evaluated separately. Lockfile changes must be generated by the package manager rather than edited manually.

### Docker

Base images remain version- and digest-pinned. A Dependabot proposal does not remove the requirement to verify the exact multi-platform digest and run the Docker build checks.

### GitHub Actions

Major action revisions remain separate for manual review, particularly where permissions, checkout behavior, caching, or artifact handling could change.
